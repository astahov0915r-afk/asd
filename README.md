# Сайт подбора техники

Теперь это серверный сайт с API и SQLite базой.

Возможности:
- фильтры и подбор техники в интерфейсе;
- импорт базы из `Excel` (`.xlsx`, `.xls`) и `JSON` (`.json`);
- хранение и чтение данных через серверный API (`/api/products`);
- SQL база `SQLite` в файле `tech.db`.

## Как запустить сервер

1. Убедись, что установлен Python 3.
2. Запусти:
   - `python server.py`
3. Открой в браузере:
   - `http://127.0.0.1:8000`

## Формат данных

Колонки/поля:

`id,name,category,brand,price,ram,storage,cpu,screen,description`

Для `JSON` можно использовать:
- массив объектов товаров, или
- объект с полем `products`, где лежит массив товаров.
